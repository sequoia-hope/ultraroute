Where it stands

The router streams its work live, and the Studio shows it: pick a board and a recipe, watch copper go down, drag a part and the board reroutes with it there. The router runs in its own process behind the studio server, so the studio's code stays separate from the router's GPL code.

Best on bluebuzz-1024 is still 10 open connections with no new errors (grid router with negotiated congestion). Physics diffusion placement made every board worse; the reasons are in the roadmap.

Next: the grid router's rounds shown live, steering a run without restarting it, then the test suite as a library. Later: boards whose outline grows until they route, offered as several complete layouts.
